# Followmont — Phased Retirement (TTR) Pathway Prototype

A React prototype of the personalised screen an eligible Followmont worker
would open from their phased retirement pathway link.

Built with Vite + React + Tailwind CSS. No backend — all calculations run
in the browser, and super/TTR fields are never sent anywhere.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Outputs static files to `dist/`, ready to deploy on Vercel, Netlify, or
GitHub Pages.
